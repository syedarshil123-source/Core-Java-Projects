# 🔐 Password Generator - Core Java

A secure and user-friendly desktop Password Generator built using **Core Java** and **Java Swing**.

## ✨ Features

* Generate strong random passwords.
* Custom password length.
* Include Uppercase letters (A–Z).
* Include Lowercase letters (a–z).
* Include Numbers (0–9).
* Include Symbols (!@#$%^&*).
* Simple and clean Java Swing GUI.

## 🛠️ Tech Stack

* Java
* Java Swing
* Object-Oriented Programming (OOP)

## ▶️ How to Run

1. Open the project in VS Code or IntelliJ IDEA.
2. Run `App.java`.
3. Enter the password length.
4. Select the character types.
5. Click **Generate**.
